# Sofi 28 — descarga del regalo

[Descargar Viena.zip](https://github.com/MSaula/Sofi28/raw/refs/heads/private-download/downloads/Viena.zip)

Abre el enlace con una cuenta de GitHub que tenga acceso al repositorio privado. Descomprime el ZIP y abre `Viena.html` en el navegador. Incluye cinco fotografías de los viajes y cinco del apartamento y funciona sin servidor ni conexión.

La rama `private-download` conserva el código, las fotografías y las evidencias de validación. El acceso a estos archivos hereda los permisos del repositorio. Esta entrega no utiliza GitHub Pages ni actualiza su rama `gh-pages`.

Validación: 63 pruebas aprobadas, incluidas coordenadas y etiquetas del mapa, sincronización de traza/avión/zoom, ausencia de destino anticipado, tarjeta final sin imagen, continuidad del timeline y de la apertura del apartamento, galería ampliable, fotos originales, recorrido inverso, móvil y exportación offline. El ZIP contiene únicamente `Viena.html` y `LEEME.txt`.
